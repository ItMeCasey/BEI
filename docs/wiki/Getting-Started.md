# Getting Started

## Install

1. Install Forge for your Minecraft version: **26.1.2** (Java 25) or **1.21.1** (Java 21).
2. Download the matching `bei-forge-<version>-<release>.jar` from the [Releases](https://github.com/ItMeCasey/BEI/releases) page.
3. Put it in your `mods` folder and start the game.

Open any inventory screen (`E`): the browser is on the right edge. Hover an item and press `R` (recipes), `U` (uses) or `P` (make it your Master Project).

## Keys

| Key | Does |
|---|---|
| `R` on an item | Recipes that make it |
| `U` on an item | Recipes that use it |
| `P` on an item | Make it your Master Project (again to clear) |
| `J` | Open the full project tree |
| `H` | Show or hide the project HUD |
| `/` | Focus the search box |

All of them can be rebound under Controls, in the Barely Enough Items section.

## Servers and multiplayer

BEI works on the client alone for the item browser and search. A server that also has BEI adds:

- **26.1.2:** recipes. The 26.1.2 game only gives a client the recipes it has unlocked, so the server sends the full list. Without BEI on the server there are no recipes to show.
- **Both versions:** datapack themes, groups and hidden items, and cheat mode (which needs the server's permission).

On 1.21.1 recipes come with the game, so they appear on any server.

Cheat mode only works for creative players, operators (game master permission), and you alone in your own singleplayer world.
