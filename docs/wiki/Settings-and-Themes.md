# Settings and Themes

Click the gear next to the search box. Changes apply at once and are saved.

| Setting | Does |
|---|---|
| Item browser | show or hide the panel |
| Category icons | the filter icon row |
| Master Project HUD | show the HUD |
| HUD corner | click to move it to the next corner |
| Count ender chest | count it as owned for the tracker |
| Backdrop opacity | drag the slider; applies to every BEI window |
| Browser / Recipe / Slot backgrounds | checkboxes to turn each backdrop off |
| Custom grid size | use the columns and rows below for the browser grid and recipe ingredients |
| Grid columns / rows | 1 to 30 each |
| Theme | click to cycle Dark, Light and datapack themes |
| Cheat items in | Cursor or Inventory (see [Cheat Mode](Cheat-Mode)) |
| Open project tree | the full tree screen |

Hover any row for a description. Drag the title bar to move the window.

## Themes

BEI ships a dark and a light theme. Datapacks add more: see [Datapacks](Datapacks).
